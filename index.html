HSK 1 / Conversational Chinese 301
LESSON 01 ၂၅ ပုဒ် အသံဖိုင်

第一课：你好！ သင်ခန်းစာ (၁) : မင်္ဂလာပါ

အခြေခံ နှုတ်ဆက်စကား (၄) မျိုး၊ တရုတ်အသံလှိုင်း ၄ မျိုး (Tones) နှင့် မြန်မာအသံထွက် နှိုင်းယှဉ်ချက်၊ ၃ သံ နှစ်လုံးဆင့်ပါက ၂ သံ ပြောင်းဖတ်ရသော စည်းမျဉ်းနှင့် SVO ဝါကျတည်ဆောက်ပုံ။

你好 你好吗 我很好 我也很好
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 02 ၃၄ ပုဒ် အသံဖိုင်

第二课：你身体好吗？ သင်ခန်းစာ (၂) : ကျန်းမာရေး ကောင်းရဲ့လား

မနက်ခင်း နှုတ်ဆက်ခြင်း (你早)၊ ကျန်းမာရေး မေးမြန်းခြင်း၊ ကျေးဇူးတင်စကား (谢谢)၊ လေးစားသမှု အခေါ် (您)၊ "都" (အားလုံး) သဒ္ဒါသုံးစွဲပုံ၊ လျှာလိပ်သံများနှင့် ဂဏန်းများ (၁ မှ ၁၀ အထိ)။

你早 你身体好吗 谢谢 再见 一至十
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 03 ၄၃ ပုဒ် အသံဖိုင်

第三课：你工作忙吗？ သင်ခန်းစာ (၃) : မင်း အလုပ်များလား

အလုပ်အကိုင် မေးမြန်းခြင်း၊ "不" ၏ ၄ သံ $\to$ ၂ သံ ပြောင်းဖတ်ပုံ (Tone Sandhi)၊ အတိုင်းအတာပြ စကားလုံးများ (不, 不太, 很, 太...了)၊ "呢" အမေးပစ္စည်းနှင့် မိသားစု ဆွေမျိုးဇယား။

你工作忙吗 很忙你呢 我不太忙 爸爸妈妈 不的变调
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 04 ၆၁ ပုဒ် အသံဖိုင်

第四课：您贵姓？ သင်ခန်းစာ (၄) : သင့်မျိုးရိုးအမည် မည်သို့ခေါ်ပါသလဲ

မိတ်ဆက်ခြင်း (Making an Acquaintance)၊ နာမည်နှင့် မျိုးရိုးမေးနည်း၊ 是/不是 သုံးစွဲပုံ၊ တရုတ်နာမည် ဖွဲ့စည်းပုံနှင့် ယဉ်ကျေးမှု၊ “吗” နှင့် အမေးစကားလုံးများ (什么 / 谁 / 哪儿)။

我叫玛丽 您贵姓 你叫什么名字 她不是老师 认识你很高兴
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 05 • MILESTONE 🏆 ၆၄ ပုဒ် အသံဖိုင်

第五课：我介绍一下儿 သင်ခန်းစာ (၅) : ကျွန်မ မိတ်ဆက်ပေးပါရစေ

မိတ်ဆက်ပေးခြင်း (Introductions)၊ ပိုင်ဆိုင်မှုပြ "的" သုံးစွဲပုံနှင့် ဖြုတ်ပယ်ခြင်း၊ နေရာပြကြိယာများ (去/在/回)၊ "一下儿" သဒ္ဒါနှင့် ယဉ်ကျေးသော အမေးများ။

他是谁 我介绍一下儿 你去哪儿 张老师在家吗 请进
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 06 • UNIT 2 START 🚀 ၆၉ ပုဒ် အသံဖိုင်

第六课：你的生日是几月几号？ သင်ခန်းစာ (၆) : မင်းရဲ့မွေးနေ့က ဘယ်လ၊ ဘယ်ရက်လဲ

ရက်စွဲ (年-月-日/号)၊ တစ်ပတ်တာ ၇ ရက် (星期一 မှ 星期天/日)၊ အချိန်ပြနာမဝိသေသနဝါကျ (Nominal Predicates)၊ နေ့တစ်နေ့၏ အချိန်အပိုင်းအခြား (၄) မျိုးနှင့် အကြံပြုမေးခွန်း (...好吗)။

你的生日 几月几号 星期天 上午/下午 ……好吗
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 07 • INQUIRY 2 👨‍👩‍👧‍👦 ၈၃ ပုဒ် အသံဖိုင်

第七课：你家有几口人？ သင်ခန်းစာ (၇) : မင်းတို့အိမ်မှာ မိသားစုဝင် ဘယ်နှစ်ယောက် ရှိသလဲ

မိသားစုဝင် အခေါ်အဝေါ်များ၊ မိသားစု ရေတွက်စကားလုံး "口" (kǒu)၊ "有"字句 ပိုင်ဆိုင်မှုပြဝါကျ (❌ 不有 -> ✓ 没有)၊ "在" နေရာပြစကားစု (在+နေရာ+ကြိယာ) နှင့် "两" vs "二" ခွဲခြားသုံးစွဲပုံများ။

你家有几口人 没有孩子 在大学工作 两口人 结婚了
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
LESSON 08 • DAILY LIFE ⏰ ၇၀ ပုဒ် အသံဖိုင်

第八课：现在几点？ သင်ခန်းစာ (၈) : အခု ဘယ်နှစ်နာရီ ရှိပြီလဲ

အချိန်နာရီနှင့် မိနစ် ပြောဆိုခြင်း (Telling Time)၊ နာရီလက်တံ စည်းမျဉ်းများ (点 / 分 / 半 / 一刻 / 差)၊ အချိန်ပြ ကြိယာဝိသေသန (Time Adverbial) နှင့် မြန်မာဝါကျ တည်ဆောက်ပုံ ထပ်တူညီမှု (S + Time + Place + V + O)၊ "两点" စည်းမျဉ်းနှင့် နေ့စဉ် လှုပ်ရှားမှုများ။

现在几点 七点二十五分 差一刻八点 什么时候去 两点整 六点半起床
▶️ သင်ခန်းစာ စတင်မည် 📝 စာအုပ်
