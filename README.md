# Conversational Chinese for Burmese Speakers
### တရုတ်စကားပြော အခြေခံ (၃၀၁) ဝါကျ - မြန်မာသင်သားများအတွက် အထူးပြုပြင်ရေးသားချက်

An interactive, offline-ready Chinese learning course tailored specifically for Burmese speakers, adapted from the proven *Conversational Chinese 301 (汉语会话301句)* curriculum.

---

## 🌟 Features
* **Studio-Quality Neural Audio**: Authentic Chinese pronunciation powered by Microsoft Neural TTS (`Xiaoxiao` & `Yunxi`).
* **Multi-Speaker Dialogues**: Realistic male and female voice actors with conversational pauses.
* **Custom SVG Visual Diagrams**:
  * 4 Tones 5-pitch curves mapped to Burmese tones (*မား~, မာ?, မာ့..ဟား, မတ်!*).
  * 3rd Tone Sandhi rule ($3 + 3 \to 2 + 3$).
  * Word order contrast: Chinese SVO vs Burmese SOV.
  * Hanzi character radicals and etymology (*亻 Person, 女 Woman, 心 Heart*).
  * 1 to 10 number flashcards with Burmese numerals.
* **Interactive Self-Assessment**: Quizzes with instant feedback.
* **Mobile & Offline Ready**: 100% self-contained static HTML.
